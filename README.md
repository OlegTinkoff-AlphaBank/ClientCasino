# CasinoClient — Avalonia-клиент, минималистичный тёмный дизайн

Desktop-приложение (MVVM), подключено к API по путям из твоего Swagger
(`api/v1.0/...`). Дизайн — один акцент (индиго), без градиентов и декора,
много воздуха.

## Запуск

```bash
cd CasinoClient
dotnet restore
dotnet run
```

Сервер должен быть поднят на `https://localhost:5294` — поменяй в
`Services/ApiClient.cs`, строка `BaseUrl`, если адрес другой.

## ⚠️ Что нужно обязательно сверить с реальным сервером

Я видел только **список путей** в Swagger, не тела запросов/ответов —
поэтому часть DTO в `Models/Dtos.cs` это обоснованные предположения,
а не точная копия. Проверь и поправь:

| DTO | Где используется | Что может отличаться |
|---|---|---|
| `UserProfileDto` | `GET /User/me` | Реальные имена полей в ответе |
| `PlayDto` / `PlayResultDto` | `POST /Game/bet` | Взял `GameId`+`BetAmount` из твоего же кода `PlayRoundByGameIdAsync`, но ответ (`PlayResultDto`) — предположение |
| `DonationDto` | `GET /Donation/list` | Форма элемента истории |
| `DonateRequestDto` / `DonateResponseDto` | `POST /Donation/donate` | Не видно из списка путей, нужно ли тело запроса вообще, и что возвращает сервер (код для доната? ссылка? и то, и другое?) |
| `CheckDonateResponseDto` | `POST /Donation/check_donate` | Нужен ли параметр (id доната) или сервер сам проверяет "последние донаты" по токену |
| `AuthResponseDto` (для refresh) | `GET /User/refresh` | Необычно, что это **GET** без тела — я предположил, что сервер сам достаёт refresh-токен откуда-то на своей стороне. Если это не так и токен нужно передавать явно — придётся переделать на `POST` с телом |

Самый быстрый способ свериться — открой каждый эндпоинт в Swagger,
разверни, глянь Example Value в Schema, и поправь соответствующий record
в `Dtos.cs`. Если поле называется иначе — **приложение просто не упадёт**,
но нужное значение будет `null`/`0`, и это не сразу заметно, так что лучше
свериться сразу, а не дебажить потом "почему баланс не показывается".

## Структура

```
CasinoClient/
├── Models/Dtos.cs         контракты запросов/ответов
├── Services/ApiClient.cs   HTTP-обёртка, один экземпляр на всё приложение
├── ViewModels/             Login, Register, Shell (навигация), Games,
│                           GameDetail (ставка), Donations, Profile
├── Views/                  соответствующие .axaml
└── Styles/Theme.axaml      минималистичная тёмная тема, один акцент
```

## Что дальше

- **Экран истории ставок** (`GameRound`/история игр) — по Swagger такого
  эндпоинта не видно (`GET /Donation/list` — только донаты, не ставки).
  Если он есть под другим путём — скажи, добавлю экран.
- **Автообновление access-токена** — `ApiClient.RefreshTokenAsync()` есть,
  но нигде пока не вызывается автоматически при истечении токена (401).
  Можно добавить `DelegatingHandler`, который сам ловит 401 и рефрешит —
  скажи, если нужно.
